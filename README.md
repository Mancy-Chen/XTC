# XTC: Longitudinal MRI Radiomics and Verbal Memory

Analysis code for a secondary analysis of the prospective Netherlands XTC Toxicity (NeXT) cohort: 95 initially XTC-naive participants, of whom 47 initiated use and 48 remained naive.

## Start here

- [Current analysis methods, inputs, and running instructions](02_Final_analysis/README.md)
- [Manuscript table/figure mapping and captions](02_Final_analysis/MANUSCRIPT_OUTPUTS.md)
- [Validation of the current release](02_Final_analysis/VALIDATION.md)

The current pipeline uses 10,000 stratified bootstrap resamples for exploratory between-group correlation comparisons selected after within-group FDR correction. It no longer runs label permutations, group-by-volume-change slope tests, nested cross-validation, or nested/reduced-model comparisons. Behavioral ANCOVA F-tests and descriptive regression lines in Figure 1 are retained.

## Repository structure

- `01_Radiomics_extract_Features/`: MRI feature-extraction utilities.
- `02_Final_analysis/Code/`: analysis, table, and figure-generation scripts.
- `02_Final_analysis/Input/`: restricted local input CSVs (not published).
- `02_Final_analysis/Output/`: generated local results (not published).

Participant-level data remain excluded from this public repository, including pseudonymized data and intermediate participant scores. Obtain the six approved input CSVs through the study's data-sharing process. The code does not require original participant identifiers or SPSS files.

## MRI feature extraction

`Extract_first_order_shape_features.py` extracts shape and first-order features from the left/right hippocampus and thalamus. `Extract_voxel_volume_whole_brain.py` extracts regional VoxelVolume, and `Extract_whole_brain_volume.py` parses segmentation statistics including BrainSegVol.

For the manuscript, FastSurfer segmentation was performed on SynthSR-generated non-contrast T1-weighted images; the aligned masks were applied to the original contrast-enhanced T1-weighted images for radiomic intensity extraction. Configure the extraction scripts' image, segmentation, and output paths for the local dataset. These utilities are not executed by the statistical runner, and the approved analysis-ready CSVs are not regenerated by it. Typical extraction dependencies are `numpy`, `pandas`, `nibabel`, `SimpleITK`, and `pyradiomics` (version 3.0.1 for the manuscript).

BrainSegVol is a measured global brain-volume covariate, not intracranial volume. The analyses are intended for research reproducibility, not individual clinical prediction.

## Quick run

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r 02_Final_analysis/requirements.txt
# Place the six approved CSVs under 02_Final_analysis/Input/ first.
python 02_Final_analysis/Code/run_all.py
```

On Windows, activate with `.venv\Scripts\activate`.
